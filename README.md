# Hotel Booking Data Analysis & Dashboard

## 📊 Project Overview

This project analyzes hotel booking data using Microsoft Excel to identify booking patterns, cancellation trends, customer behavior, pricing, and room allocation patterns.

The dataset contains **119,390 hotel booking records** from City Hotel and Resort Hotel.

## 🛠️ Tools Used

- Microsoft Excel
- Excel Formulas
- PivotTables
- PivotCharts
- Data Analysis
- Dashboard Design

## 🔎 Analysis Performed

The project includes analysis of:

- Hotel performance
- Booking cancellations
- Monthly booking trends
- Average Daily Rate (ADR)
- Customer type cancellation
- Deposit type cancellation
- Room allocation
- Key performance indicators (KPIs)
- Dashboard visualization

## 📈 Key Findings

- **Total Bookings:** 119,390
- **Canceled Bookings:** 44,224
- **Overall Cancellation Rate:** 37.04%
- **City Hotel Cancellation Rate:** 41.73%
- **Resort Hotel Cancellation Rate:** 27.76%
- **Average ADR:** 101.83
- **Average Stay:** 3.43 nights

## 📊 Dashboard

The Excel dashboard presents key booking and cancellation metrics along with visualizations covering hotel performance, monthly booking volume, customer types, deposit types, and room allocation.
