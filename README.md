# Hotel Booking Data Analysis & Dashboard

## 📊 Project Overview

This project analyzes hotel booking data using Microsoft Excel to identify booking patterns, cancellation trends, customer behavior, pricing, and room allocation patterns.

The dataset contains **119,390 hotel booking records** from City Hotel and Resort Hotel.

## 🛠️ Tools Used

- Microsoft Excel
- Excel Formulas
- PivotTables
- PivotCharts
- Data Analysis
- Dashboard Design

## 🔎 Analysis Performed

- Hotel performance analysis
- Booking cancellation analysis
- Monthly booking trends
- Average Daily Rate (ADR) analysis
- Customer type cancellation analysis
- Deposit type cancellation analysis
- Room allocation analysis
- KPI development
- Dashboard visualization

## 📈 Key Findings

- **Total Bookings:** 119,390
- **Canceled Bookings:** 44,224
- **Overall Cancellation Rate:** 37.04%
- **City Hotel Cancellation Rate:** 41.73%
- **Resort Hotel Cancellation Rate:** 27.76%
- **Average ADR:** 101.83
- **Average Stay:** 3.43 nights
